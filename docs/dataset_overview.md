# MIT-BIH Arrhythmia Dataset Overview

## Key Facts
- 48 half-hour two-lead Holter recordings sampled at 360 Hz.
- Leads MLII and V5 are provided for most records; annotations follow the AAMI heartbeat taxonomy.
- Files ship in PhysioNet format: `.dat` waveforms, `.hea` metadata, `.atr` annotation rhythms, `.xws` additional waveforms.

## Repository Layout
```
data/mitbih
├── 100.dat / 100.hea / 100.atr / ...
├── ANNOTATORS, RECORDS, SHA256SUMS.txt
└── mit-bih-arrhythmia-database-1.0.0.zip
```
`data/processed` holds segmented beats, filtered signals, and feature tables generated by preprocessing scripts.

## Recommended Splits
1. **Record-level splits**: keep records for patients separate between train/val/test (e.g., 80/10/10 over record IDs) to avoid leakage.
2. **Beat-level balancing**: downsample dominant Normal beats and oversample PVC/APB classes when training supervised models.

## Access & Tooling
- Use the `wfdb` Python package or our loader (`src/preprocessing/load_mitbih.py`) to read signals with annotation alignment.
- Keep raw data immutable; derived artifacts live under `data/processed` and can be regenerated from notebooks or scripts.
